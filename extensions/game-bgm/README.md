# THPrac C7 背景音乐替换

启动 C7，打开 **工具 → 背景音乐**，选择作品。界面会从 THPrac 游戏库取得安装目录并自动读曲目。优先使用默认启动项，其次使用第一个仍有效的启动项。使用 thcrap 时，读取其配置指向的游戏目录。如果没有有效路径，先到游戏库配置。界面提供 TH06–TH20 整数作以及使用 `thbgm.dat` 的 TH09.5、TH12.5、TH12.8、TH14.3、TH16.5、TH18.5。选择一首曲目，再点「选择替换音频」。音频可以来自任意文件夹，可以一次选好几首再点「应用更改」。重启游戏后生效。选中已替换的曲目也可以单独恢复。

换曲界面需要新版 `launcher_layout.thp.dll`、`game_bgm.thp.dll` 以及包内的 Python 脚本。把插件包的 `plugins` 内容放在 C7 启动器旁，或者放在 `%APPDATA%\thprac\plugins`。若启动器旁已有同名插件，应更新那份，它的加载优先级更高。替换前先退出 C7 和游戏。

需要 PATH 中的 Python 3.10 或更新版本。界面使用 FFmpeg 解码 WAV、MP3、FLAC、M4A、AAC、OGG、Opus 等格式，可在「工具路径」中选择自己的 `ffmpeg.exe`。曲目表会尝试从游戏目录读取，或用 `thdat` 从同版本的主数据包提取。也可以直接选择已提取的 `thbgm.fmt` 或 `thbgm_tr.fmt`。

随包的 `thdat.exe` 来自 [Touhou Toolkit 917a3d3](https://github.com/thpatch/thtk/tree/917a3d3858850f01276b7fb5b9327e2c24d27d5b)，以 Win32 静态方式构建。授权随包附带。

单次播放同时需要 `bgm_repack.exe`。从源码构建该工具时，将 `THPRAC_THTK_SOURCE` 指向上述 THTK 源码目录，将 `THPRAC_THTK_BUILD` 指向同一份源码的 Win32 静态构建目录。

双击原曲或使用「添加候选曲」可以打开文件选择器。同一首原曲可添加多首候选，选中后固定用该候选，或开启「每次启动游戏随机选一首」。随机结果在本次游戏进程内保持一致。

界面把生成文件写入游戏目录的 `thprac-bgm/manager`。新替换默认播放一次，结束后静音，超过原曲槽长度的部分会被截短。单次播放所需的循环元数据写在独立的主数据包副本里。应用后请通过 C7 重新启动游戏，使插件能在读取主数据包时接管单次播放。红魔乡需要使用 WAV 音乐模式。

选择曲目后会显示原版循环起点和终点。红魔乡读取 `.pos` 的 PCM 帧号，其他受支持作品用 `thbgm.fmt` 的字节位置除以每帧字节数。勾选「循环播放替换曲」后，可继续使用原来的循环方式，也可以为当前候选指定自己的循环起止秒数。工具会将替换音频的前奏和循环段分别对齐到原版长度。已有方案沿用原来保存的播放行为。

## 替换预设

新生成的替换音频会在开头短暂淡入，并在循环接缝两侧短暂降低音量，减轻跳音。已有替换可选中曲目，点「重新生成替换」再应用。游戏切走旧曲的时机仍由游戏控制。

在「替换预设」中可将已应用的整套替换保存为命名方案，包含每首曲目的音频路径和自定义循环点。可以更新、改名、删除或整套应用。预设按当前游戏安装和音乐包保存，源音频请保留在原位置。应用方案时，方案没有包含的曲目会退出界面替换。

## 旧版手动替换

旧版手动替换仍可用。它和界面生成的文件分开保存，界面生成的对应文件优先。恢复界面替换后，游戏会回到原音乐，或继续使用此前手动放进 `thprac-bgm` 的旧版替换。

例如，游戏原本读取 `bgm/th06_01.wav`，就把新 WAV 放到游戏 EXE 旁的 `thprac-bgm/th06_01.wav`。新 WAV 必须使用与原曲一致的 PCM 格式和采样帧数，游戏继续使用原来的循环点。插件逐首检查 WAV，缺失或不匹配时播放原曲。请在游戏设置中选择 WAV 音乐。

用随包附带的 Python 3.9+ 工具可以生成符合原曲长度的 WAV。先进入存放 `prepare_bgm.py` 的目录，再运行：

```powershell
python .\prepare_bgm.py th06 "C:\Games\TH06\bgm\th06_01.wav" "D:\Music\my-title.wav" --fit
```

## 使用 thbgm.dat 的整数作

从该游戏版本的主数据包提取 `thbgm.fmt` 到工作目录，可使用 [Touhou Toolkit](https://www.thpatch.net/wiki/Touhou_Patch_Center%3ATHTK)。体验版可能使用 `thbgm_tr.fmt` 和 `thbgm_tr.dat`。先列出曲目、PCM 格式、帧数和循环点：

```powershell
python .\prepare_bgm.py archive "C:\Games\TH08\thbgm.dat" "D:\Work\thbgm.fmt"
```

将替换 WAV 命名为列表中的曲目名，可一次传入多首：

```powershell
python .\prepare_bgm.py archive "C:\Games\TH08\thbgm.dat" "D:\Work\thbgm.fmt" "D:\Music\th08_01.wav" "D:\Music\th08_03.wav" --fit
```

工具会在游戏目录下生成独立的 `thprac-bgm/thbgm.dat`，需要约一个原音乐包大小的额外磁盘空间。它保留原包的曲目偏移、PCM 格式、长度和循环点，原样复制未选的曲目。请使用同一游戏安装的原包和曲目表。插件会检查替换包大小，曲目布局由生成工具保证。重新生成前，先把旧的替换包移出 `thprac-bgm`。

两种模式的 `--fit` 都会把过长的 WAV 截到原长度，把过短的 WAV 从头重复到原长度。省略该参数可要求长度精确匹配。工具不会重采样，也不会调整循环点。想让循环接得自然，可按原循环位置编辑音频后再导出 PCM WAV。

插件依赖游戏主 EXE 的标准 Windows 文件导入。已经打开的音乐文件要等重启才会切换。如果另一套模组接管了相同的文件导入，该导入上的原有行为会继续生效。
